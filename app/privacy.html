Privacy Policy

Publicador de Reels — personal-use application · Last updated: October 6, 2026 · Versión en español

This policy describes how the Publicador de Reels application handles information. The application is a personal command-line tool that its own author uses to publish short video clips of their podcast to their own social media accounts.

No third-party data is collected

The application has no users other than its author. There is no sign-up, no login for third parties, no forms, and no visitor analytics.

The application does not collect, process, store, or transmit personal information about any other person.

What information it accesses

The application accesses only its author's accounts, with the author's explicit authorization, in order to:

  • Publish video files to the author's own accounts and pages
  • View statistics for the author's own posts (for example, how many people watched a video)
  • Read the username of the author's own accounts, to confirm that the connection is correct

It does not access content, messages, contact lists, or data belonging to other people.

Where information is stored

All information is stored locally, on the author's computer:

  • Access credentials, in a local configuration file that is not shared or uploaded to any repository
  • A record of which videos were published and when, in a local database

There is no server, no cloud database, and no remote copy of this information.

Third-party services

To publish, the application communicates with the application programming interfaces (APIs) of the platforms where the author publishes content:

  • Meta (Facebook and Instagram)
  • Google (YouTube)
  • X (formerly Twitter)
  • TikTok

Each platform receives only the video and its caption, so that they can be published. Each platform's use of that information is governed by its own privacy policy.

TikTok

The connection to TikTok uses its official interfaces: Login Kit, so the author can log in and authorize the application, and the Content Posting API, to upload and publish the author's clips. The application requests only these permissions:

  • user.info.basic: to display the connected account name
  • video.upload and video.publish: to send the author's clips to TikTok

TikTok receives only the video, its caption, and the privacy level the author chooses, and nothing is published without the author's confirmation. The application does not read messages, follow accounts, like, comment, or obtain information about other TikTok users. Access can be revoked at any time in TikTok under Settings and privacy > Security & permissions > Apps and services.

Retention and deletion

Because the data resides only on the author's computer, it is deleted by deleting the corresponding files. The author can revoke the application's access to their accounts at any time from each platform's security settings, without needing to ask anyone.

Changes

If the way the application works changes in a way that affects what is described here, this page will be updated along with its date.

Contact

This application is for personal use and is not available to the public. It does not provide services to third parties or process other people's information.
